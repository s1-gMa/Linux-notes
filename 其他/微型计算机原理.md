# 二 8086微处理器
## 2.1 8086结构
1.简要: 16位 16根数据线 20根地址线
==2.组成:==
**BIU: 总线接口单元**
- 完成CPU与存储器或IO设备之间的数据传送
- 段寄存器
	- CS 代码段    DS 数据段    SS 堆栈段    ES 附加数据段
- 指令指针寄存器
	- IP 下一条指令在代码段中的偏移地址
- 20位地址加法器
- 指令队列缓冲器
	- 让**BIU提前取指 EU持续执行** 通过缓冲实现取指和执行的**并行** 提高CPU效率

<br>**EU: 执行单元**
- 执行指令
- 算术逻辑单元: 进行算术和逻辑运算
- 标志寄存器: 存放CPU运算结果的状态特征和控制标志
	- 状态标志位: CF 进位标志位    PF 奇偶标志位    AF 辅助进位标志位    ZF 零标志位    SF 符号标志位    OF 溢出标志位
	- 控制标志位: TF 跟踪标志位    IF 中断允许标志位    DF 方向标志位
- 数据暂存寄存器: 暂存参与运算的数据
- 通用寄存器
- 控制电路: 产生控制信号

其他:
- 逻辑地址: 描述数据或指令在某一段中的位置
- 物理地址: 用于访问存储器的20位实际地址

<br>

- ==**BIU**：形成物理地址（段基址+偏移）、**取指**、指令队列、与存储器/I/O总线读写==
    
- ==**EU**：指令译码与执行、ALU运算、通用寄存器/标志寄存器操作==

## 一、Jcc 指令速记表（指令 + 含义）

### 1）按“等于/不等于（看 ZF）”

- **JE / JZ**：相等 / 为零则跳转（**ZF=1**）
    
- **JNE / JNZ**：不等 / 非零则跳转（**ZF=0**)
    

### 2）无符号比较（看 CF / ZF）

- **JA**：无符号大于（**CF=0 且 ZF=0**）
    
- **JAE / JNB / JNC**：无符号大于等于 / 不低于 / 无进位（**CF=0**）
    
- **JB / JNAE / JC**：无符号小于 / 不大于等于 / 有进位（**CF=1**）
    
- **JBE / JNA**：无符号小于等于 / 不大于（**CF=1 或 ZF=1**）
    

### 3）有符号比较（看 SF / OF / ZF）

- **JG**：有符号大于（**ZF=0 且 SF=OF**）
    
- **JGE**：有符号大于等于（**SF=OF**）
    
- **JL**：有符号小于（**SF≠OF**）
    
- **JLE**：有符号小于等于（**ZF=1 或 SF≠OF**）
    

### 4）进位/溢出/符号（单标志）

- **JC**：有进位/借位（**CF=1**）
    
- **JNC**：无进位/无借位（**CF=0**）
    
- **JO**：溢出（**OF=1**）
    
- **JNO**：不溢出（**OF=0**）
    
- **JS**：结果为负（**SF=1**）
    
- **JNS**：结果非负（**SF=0**）
    
- **JP / JPE**：奇偶为偶（**PF=1**）
    
- **JNP / JPO**：奇偶为奇（**PF=0**）
    

### 5）CX 计数专用（循环相关）

- **JCXZ**：CX=0 则跳转（只检查 **CX**，不看标志位）
    

> 记忆：
> 
> - **无符号**：Below/Above → 看 **CF**
>     
> - **有符号**：Less/Greater → 看 **SF 与 OF**
>     
> - **等不等**：看 **ZF**
>
